# Deep Dish sync — сервер семейной синхронизации

FastAPI + SQLite (WAL, synchronous=FULL). Один эндпоинт обмена `POST /sync` (SPEC §4–5):
LWW по `updatedAt`, tombstone-удаления (очистка старше 90 дней), дневники приватные,
каталог общий, события метрик едут попутно.

## Установка на QNAP (Container Station)

1. Скопируйте папку `backend/` на NAS (например, `/share/ContainerStation/deepdish/`).
   Папку `data/` разместите на RAID-томе (подстроечите путь в `compose.yaml`, volume `./data:/data`).
2. Container Station → Создать приложение → загрузите `compose.yaml` из папки
   (или в SSH: `cd /share/ContainerStation/deepdish && docker compose up -d`).
3. Сервис поднимется на порту **8687**. Проверка: `http://<IP-NAS>:8687/healthz` → `{"ok": true}`.

## Подключение семьи

1. **Первый участник (вы)**: в приложении Настройки → Семья и синк → адрес
   `http://<IP-NAS>:8687`, имя → «Подключить». Первый становится **admin**, его токен —
   в поле «админ-токен» не нужен. Свой админ-токен после подключения можно посмотреть:
   Настройки → Семья и синк (он в состоянии устройства; для передачи другим скопируйте
   из строки состояния — сейчас токен admin виден в `/admin/users` или в localStorage `dd-sync`).
2. **Остальные**: тот же адрес + имя + ваш админ-токен в третьем поле.
3. Синк: вручную кнопкой, автоматически при старте и появлении сети (раз в 5 минут).

## Безопасность и доступ извне

- Пока — только из домашней сети (http). Доступ извне и TLS: Headscale + Caddy
  (следующий этап M2, SPEC §6). Не открывайте порт 8687 в интернет без TLS.
- Токен юзера = доступ к его дневнику. Админ-токен = право подключать новых участников.
- На сервере нет ничего идентифицирующего: id, псевдоним, еда, вес (SPEC §2).

## Разработка

```bash
pip install -r requirements.txt
python -m uvicorn server:app --port 8687   # локально, БД в ./data/
```
